# FlavorCraft — Recipe Finder & Kitchen Dashboard

A feature-rich recipe manager built with pure HTML, CSS, and JavaScript.

## Features

- Browse recipes with search, category/difficulty filtering, and sorting
- Tabs: **All Recipes**, **Favorites**, **Pantry Ready**, and **My Creations**
- Recipe detail modal with adjustable serving sizes and scaled ingredient amounts
- Favorites you can toggle per recipe
- Pantry manager that highlights recipes you can cook with what you have
- Grocery list generation from recipe ingredients
- Add, edit, and delete your own custom recipes
- Everything persists to `localStorage` (recipes, favorites, pantry, and grocery list)
- Responsive layout and accessible controls

## Notes

- Ships with a built-in set of starter recipes.
- All data stays in your browser.

## Run

Open `index.html` in a modern browser.
